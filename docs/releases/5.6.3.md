# HF Model Downloader 5.6.3 · Routed Tree

5.6.3 修复了 macOS 与 Windows 上应用无法自动使用系统代理、连接和文件清单长时间超时的问题，并把平铺文件表改成可折叠的仓库目录树。模型源与网络通道现在是两个独立维度，但统一收纳在“连接策略”区域中。

## 中文 Release Notes

### 网络连接

- 新增自动推荐、跟随系统代理、直连和自定义代理四种网络方式。
- 自动模式并行短测可用候选，根据连接成功与延迟推荐通道；系统未配置代理时明确推荐直连。
- Hugging Face 官方源、HF Mirror 与网络通道可以独立切换，读取清单和实际下载始终使用同一条已选通道。
- 自定义代理支持无凭证的 HTTP、HTTPS、SOCKS4 和 SOCKS5 地址；代理偏好只保存在本机。
- API 连接改用 Electron Chromium 网络栈，以便在 macOS 和 Windows 上遵循系统代理配置。

### 仓库目录树

- 文件清单按真实路径聚合成目录，默认折叠文件夹，不再一次铺开所有文件。
- 文件夹可以逐层展开或收起，并显示后代文件数、已选数量和汇总大小。
- 文件可逐个选择；文件夹复选框可整组选中或取消全部后代，部分选择时显示半选状态。
- 搜索和族群筛选会保留并展开匹配文件的祖先目录；在筛选结果中操作文件夹仍作用于完整文件夹。
- 保留“运行所需”“仅模型权重”“文档预览”和当前结果等快速方案。

### 安全与验证

- 每次网络重定向都会重新执行 HTTPS、私网和 loopback 边界检查。
- Authorization 离开 `https://huggingface.co` 前会被强制移除；非官方源继续禁止接收 Token。
- macOS 实机已验证系统代理检测、官方源和 HF Mirror 清单、目录树交互及小文件下载。
- Windows x64 包在 macOS 上交叉构建并完成静态、结构、隐私和校验和验证，尚未在 Windows 真机启动。

## English Release Notes

### Network routing

- Added automatic recommendation, system proxy, direct, and custom proxy modes.
- Automatic mode probes viable routes in parallel and recommends a successful low-latency route; direct is preferred when no system proxy is configured.
- Model source and network route remain independent, while manifest and download requests share the same selected transport.
- Custom proxy settings accept credential-free HTTP, HTTPS, SOCKS4, and SOCKS5 URLs and remain local to the device.
- API traffic now uses Electron's Chromium network stack so macOS and Windows system proxy settings can be honored.

### Repository tree

- Replaced the fully expanded flat file table with a path-aware, collapsed repository tree.
- Folders can be expanded individually and show descendant counts, selection state, and aggregate size.
- Files remain individually selectable; folder checkboxes select or clear every descendant and expose a mixed state for partial selections.
- Search and family filters preserve matching ancestors and expand their paths. Folder selection still targets the complete folder while filtered.
- Existing runtime, weights, documentation, and current-result presets remain available.

### Security and verification

- HTTPS, private-address, and loopback checks are re-applied on every redirect.
- Authorization is stripped before leaving `https://huggingface.co`, and non-official sources remain unable to receive a Token.
- macOS runtime verification covered system-proxy detection, official and mirror manifests, tree interactions, and a small real download.
- The Windows x64 archive was cross-built on macOS and passed static, structure, privacy, and checksum validation, but was not launched on Windows hardware.

These portable packages remain unsigned. SHA-256 proves integrity against this GitHub Release but does not replace platform publisher signing or notarization.
