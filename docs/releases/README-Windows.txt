HF Model Downloader 5.6 Sol for Windows

便携使用 / Portable use
1. 解压 ZIP，或直接使用发布页中的 portable EXE。
2. 双击 “HF-Model-Downloader-*-windows-x64-portable.exe” 启动。
3. 应用已包含 Electron 与运行依赖，不需要安装 Node.js、npm 或 Python。

首次运行 / First launch
当前版本没有 Windows Authenticode 签名。若 SmartScreen 提示未知发布者，请先确认文件来自 https://github.com/Yifo98/HF_Model_Downloader/releases 且 SHA-256 与同一 Release 的 SHA256SUMS.txt 一致，再选择“更多信息 → 仍要运行”。

数据位置 / Data location
便携版数据、缓存和默认下载目录位于 EXE 同目录的 HF_Model_Downloader_Data/。移动程序时可一并移动该目录；发布 ZIP 本身不包含任何用户数据。

完整更新日志与 SHA-256 校验值见同一 GitHub Release。
