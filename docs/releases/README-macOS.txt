HF Model Downloader 5.6 Sol for macOS

便携使用 / Portable use
1. 解压 ZIP。
2. 双击 “HF Model Downloader.app” 启动。
3. 应用已包含 Electron 与运行依赖，不需要安装 Node.js、npm 或 Python。

首次运行 / First launch
当前版本没有 Apple Developer ID 签名和公证。若 Gatekeeper 拦截，请右键应用并选择“打开”，或在“系统设置 → 隐私与安全性”中确认本次打开。不要从不可信来源复制终端命令绕过系统保护。

数据位置 / Data locations
应用数据与缓存保存在当前用户目录，不会写入应用包。模型默认下载到 ~/Program/Downloads，可在应用内修改和打开。

完整更新日志与 SHA-256 校验值见同一 GitHub Release。
